# Controle de Gastos

Projeto desenvolvido em Python com o objetivo de praticar programação, manipulação de banco de dados e análise de dados.

## Funcionalidades

- Cadastro de gastos por categoria.
- Visualização dos gastos cadastrados.
- Edição de valores e datas.
- Exclusão de registros.
- Geração de relatórios com total e quantidade de gastos.
- Visualização de gráficos de gastos por categoria.

## Tecnologias utilizadas

- Python
- SQLite
- Pandas
- Matplotlib
- Seaborn

## Requisitos

- Python instalado.
- Bibliotecas listadas no arquivo `requirements.txt`.

## Instalação

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no VS Code.
3. Instale as dependências:

```bash
pip install -r requirements.txt
```

## Como executar

Execute o seguinte comando no terminal:

```bash
python controle_de_gastos.py
```

O banco de dados SQLite será criado automaticamente na pasta do projeto na primeira execução.
